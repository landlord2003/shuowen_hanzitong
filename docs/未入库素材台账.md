## 二、逐项明细

### A. 诗词语料 `tools/poetry_corpus/`（142.68 MB / 360 个文件）

**是什么**：飞花令功能的语料原料，来自开源仓库 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)（繁体原文）。

| 子目录 | 文件数 | 体积 |
|---|---:|---:|
| 全唐诗 | 314 | 128.47 MB |
| 宋词 | 24 | 8.60 MB |
| 蒙学 | 13 | 1.01 MB |
| 四书五经 | 3 | 0.16 MB |
| 诗经 / 元曲 / 楚辞 / 论语 / 曹操诗集 / 纳兰性德 | 各 1 | 合计 0.46 MB |

**用途**：**重建** `data/feihualing.json`（成品已入库，运行时直接用成品）。

**重建入口**（两个脚本，已入库）：
1. `tools/verify_poems_full.py` —— 从 chinese-poetry 官方仓库下载语料，缓存到 `tools/poetry_corpus/`
2. `scripts/build_feihualing.py` —— 读语料 → 生成 `data/feihualing.json`

**⚠️ 已知坑**（重建前必读）：
- 目录名与实际内容**不符**：`tools/poetry_corpus/全唐诗/` 里**全部是 `poet.song.*.json`（即《全宋诗》311,856 首）**，不是唐诗。此坑已在 `scripts/build_feihualing.py:31` 注释中记录。
- 若要**真正的《全唐诗》**，需另取 `poet.tang.*.json`（约 5.7 万首），当前语料里没有。

**丢失后果**：需重新从 GitHub 拉取约 130MB 语料（国内网络可能需要镜像）。**可恢复，但要联网 + 时间**。

### B. GlyphWiki 字源素材 `tools/rubbing_pipeline/glyphwiki_src_backup_8105/`（29.15 MB / 10,566 个）

**是什么**：GlyphWiki「字源」阶段字形图的**原始抓取件**，`gw_<id>.svg` 与 `gw_<id>.png` 成对。

| 类型 | 数量 |
|---|---:|
| `.png` | 5,284 |
| `.svg` | 5,282 |

**用途**：**重建** `data/dataset.bin` 中的「字源」阶段图层（成品 8105 字已入库在 `dataset.bin`，14.24MB）。

**重建入口**（已入库）：
1. `tools/rubbing_pipeline/adapters/glyphwiki.py` —— 抓取，按 `gw_<id>.svg` / `gw_<id>.png` 命名落盘
2. `tools/rubbing_pipeline/pack_all.py` —— 汇总打包进 `dataset.bin`（其中 `gw_{id}.png` → GlyphWiki「字源」，注明授权 CC BY-SA 2.1 JP）
3. `tools/rubbing_pipeline/pack_existing.py` —— 从**已抓好的 PNG** 直接打包，避免重复联网（正是为这个素材目录准备的）

**⚠️ 丢失后果（三类里最麻烦的一项）**：
- 重抓需向 GlyphWiki 发起**上万次请求**；
- 沙箱实测 **GlyphWiki 被 Cloudflare 拦截数据中心 IP**，本机环境不一定抓得动；
- 该素材是**授权链条的凭证**之一（CC BY-SA 2.1 JP，可商用、须署名、衍生同授权）——重抓时须重新核对授权与署名清单。

## 四、备份策略（当前约定）

1. **不进 Gitee**。理由：合计 +206MB，其中 B 项是 10,566 个**小文件**，git 对大量小文件效率极差，会显著拖慢所有 `clone`；且会推翻既有的 `.gitignore` 边界（仓库本职是代码 + 运行数据）。
2. **走离线盘备份**（H 盘 / 外接盘）：把本目录四类素材 + 仓库整体一起拷贝，形成可独立运行的离线副本。
   > 备注：截至 2026-09-15，H 盘 / G 盘 / F 盘均未挂载，此项待执行。
3. **运行不受影响**。另一台电脑 `git clone` 后可完整运行产品——`data/` 目录 39 个文件已全部入库（`dataset.bin`、9 个字体、`characters.json`、`feihualing.json`、`cultural.json`、全部 JS 模块）。缺的只是「重新生成数据」的能力。
