## 二、文件说明

- **`*_汉典重建表.html`** — 逐字对照表，含做法、覆盖情况、数据核验、逐字表（带筛选）、审计与边界说明。**表内字形走相对路径 `glyphs/`，本目录未随附字形图**，因此直接在浏览器打开时字形会显示为空白（详见第四节）。
- **`取图清单_*.csv`** — 逐字台账，Excel 可直接打开：汉字、通道、汉典页、字形数、原书著录、全部 SVG 直链、覆盖状态 / 风险分级。
- **`取图清单_*.json`** — 同内容机器可读版，字形列表为完整数组结构，供脚本消费。

## 三、数据来源与权利边界（重要）

**来源**：字形图取自汉典（`zdic.net`）书体栏，为**据拓本 / 简帛 / 《说文》刻本摹写的矢量图**（SVG，统一 `viewBox="0 0 400 400"`，栅格化为 PNG）。逐字附**原书著录**：

- 甲骨文 → 《甲骨文编》《甲骨文合集》体例（如 `关庫1397 合21211`）
- 小篆 → 大徐本《说文解字》卷·部·页（如 `5上.喜.101`，2821 字 100% 有）
- 简帛 → 各批材料整理报告（如 `为 郭老两 2`）

**汉典本身**：2004 年个人创办的免费聚合站，非学术机构；其价值在于**逐项标注所据底本**（《康熙字典》武英殿本、《说文》陈昌治刻本、《甲骨文编》《金文编》等），**内容不自行考释**。

⚠️ **权利口径未清，使用前须知**：

1. 汉典条款页声明 CC0 1.0（含商用），但维基等处引其旧版说明为 CC BY-NC-ND 2.5 并「拒绝用于商业途径」——**两处口径冲突**。CC0 免责条款亦声明「不排除他人对本作品主张的权利」。
2. **汉典无权处分其底本方的权利**。字形图的权利链上游是《甲骨文编》《说文》陈昌治本等**现代整理成果与刻本影印**。
3. 据此，本目录定位为：**内部研究、交叉核对、取图索引**。**接入商业产品前须换到权利链干净的底本**（自扫公有领域刻本 / 已确认可商用的开放库）。

相关考证见仓库 `output/数据来源_汉典考证与替代源.md` 与 `output/自建字形方案/02_字形图权利分层与自摹合法性判定.md`（本地目录，未入库）。

## 四、字形图的获取与重建

字形图（合计约 101 MB / 28651 个 PNG）**未纳入版本控制**——它们是可由管线重建的抓取原料，符合仓库 `.gitignore` 中 `output/` 的既有约定。

本地 `output/` 下对应目录即含完整字形：

```
output/甲骨文缺口452字_汉典取图/glyphs/          (4977)
output/简牍帛书缺口1832字_汉典重建/glyphs/        (20379，分 chuwenzi / qinwenzi)
output/篆书缺口2821字_汉典小篆重建/glyphs/        (3295)
```

**让 HTML 表格正常显示字形**：把对应目录下的 `glyphs/` 拷到本目录旁（与本 README 同级），使路径成为 `docs/汉典重建/glyphs/xxx.png`，即可本地打开完整渲染。

重建管线：`tools/zdic_pipeline/`（抓取 → 三级核验 → 栅格化 → 建表）。

## 六、边界（不藏）

1. 汉典字形是**摹写矢量**，带著录可追溯，但**非扫描拓本**；要拓本级鉴定须按著录号回原书取图。
2. 小篆栏是《说文》字形集合，混有非正篆形态（或体 233 / 古文 147 / 籀文 80 / 篆文 10 / 俗字 4 = 474 张），表中已分层标注；每字恰有 1 张正篆（2821/2821）。
3. 异体**未做择优**，一个字最多 431 个异体（「亓」），表内展示前 3 张，其余全在台账直链中。
4. 命中 100% **不等于**「产品库只需补这些字」——这只是源 docx 给出的已知子集。
5. 本次未改动任何源 docx。
