# 说文解字 App · 字形阶段缺失的两档归因（v4）

> 生成日期：2026-09-15　对象：详情页「字形演变」中**本库未收**阶段的标注文案
> 触发：原文案一律写「历史上不存在此字的X字形」，把「本库没收」错说成「历史上不存在」。

## 一、结论

缺失阶段不再一刀切，按**权威源是否著录**分两档：

| 标注 | 含义 |
|---|---|
| **有此字形，待补** | 该书体在权威字书/出土文献中已著录，**本库尚未收录** |
| **根据权威数据源，未发现有此字形** | 据汉典等字书，**该字未见**该书体字形（多为后起字/形声/简化字） |

## 二、逐字判据（v4）

先取「本库已有书体」`presentEras`（来自 `dataset.bin` 真迹，字体兜底另在运行时补），再对每个缺失阶段 S：

```
1) S ∈ {甲骨文, 金文}                    → 未发现
     本库已将早期两阶段收得较全（955/1120、2049/2072），缺者多属权威源亦无
2) ∃ p ∈ presentEras, rank(p) < rank(S)  → 有此字形，待补
     该字在更早书体已见 ⇒ 较晚书体（简帛/小篆/隶书本库覆盖明显不足）多有著录
3) present 为空 且 该字古已有之           → 有此字形，待补
     判据 isAncientChar：有反切，或 shuowen 有实质《说文》释义（未见「后起字/俗字/新造/《说文》无」标记）
4) 其余（后起字）                         → 未发现
```

书体排序 `ERA_RANK`：甲骨文 1 < 金文 2 < 大篆 3 < 简牍帛书 4 < 小篆 5 < 隶书 6。

**关键：`NO_ANCIENT_GLYPH`（3231 字）只表示「本库+字体都没有古文字形」，不等于「权威源没有」。**
例：「缇」是《说文》字头，小篆必存——若用它判定会错标「未发现」；v4 改用「有反切/实质说文释义」这一逐字判据，缇的简帛/小篆/隶改判「待补」。

## 三、判据的逐字数据支撑

8105 字交叉表（G＝本库有真迹古文字段，F＝有反切）：

| | 有反切 F | 无反切 f |
|---|---|---|
| **有古文字段 G** | 3313 | 350 |
| **无古文字段 g** | **2065** | **2377** |

- 「无真迹古文字段」共 4442 字（= 2065 + 2377）；
- 其中 `shuowen` 有实质《说文》释义（非「后起字」标记）者 **2064 字**，几乎与「有反切」的 2065 字重合（仅 7 字差：皂 希 表 的 样 粥 叟）；
- 明确标「后起字/《说文》无/俗字/新造」者 2378 字。

故 `hasFanqie || 实质说文释义` 是「古已有之」的可靠逐字判据。

## 六、已知边界（诚实声明）

- 本规则是**逐字判据驱动**，**不是**逐字「汉典有/无」查询结果——汉典侧数据只有**聚合统计**（甲骨 1120／金 2072／大篆 5055／小篆 5564／隶 2688／简帛 2420），未保存逐字索引。
- 因此个别字仍可能判错（例：有《说文》著录但确实无某出土书体字形的字，会被判「待补」）。
- 若要**逐字精确**，需重建汉典逐字索引（`docs/汉典重建/` 现有台账仅覆盖 452/1832/2821 个**非 8105 范围**的缺口字，不可直接用）。
