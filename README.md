# 说文解字 · 汉字知识库

一个本地离线可用的汉字知识工具，收录 **8105 个汉字**（《通用规范汉字表》全表：一级 3500 + 二级 3000 + 三级 1605），提供字形演变、说文原文、段玉裁注、六书、本义今义、后起字溯源等完整信息。

> 产品说明按「知识说明 → 数据来源 → 数据统计」三张知识卡片组织，便于查阅与核验。

# 知识卡片一 · 汉字知识说明

## 1.1 六书（造字法）

六书是对汉字构造方式的传统分类。本库 8105 字依许慎《说文》构形并参照现代共识标注，分布如下：

| 六书 | 字数 | 占比 | 说明 |
|---|---:|---:|---|
| 形声 | 7032 | 86.8% | 形旁表义类 + 声旁表读音，如「江」（水形工声）、「河」（水形可声）。汉字绝对主体。 |
| 会意 | 636 | 7.8% | 组合两个及以上字表新义，如「林」（双木）、「休」（人依木）、「明」（日+月）。 |
| 象形 | 281 | 3.5% | 描摹事物形状的造字法，如「日」「月」「山」「水」「木」「人」。 |
| 指事 | 26 | 0.3% | 用象征符号或在象形字上加指示符号表抽象概念，如「上」「下」「本」「末」「刃」。 |
| 会意兼形声 | 130 | 1.6% | 兼具会意与形声特征的兼类字（《说文》「某亦聲」），自成一类、单独筛选。 |
| **合计** | **8105** | **100%** |  |

> 六书 / 本义 / 今义 / 演变字段由 AI 生成，页面已标注「待核验」，上线前须人工终审（会意、指事为薄弱项，约 1100 字待复核）。

## 1.2 各种字形的起源说明

| 书体 | 起源与公版知识 |
|---|---|
| **甲骨文** | 商代晚期（约前 14–前 11 世纪）契刻于龟甲、兽骨的占卜记事文字，1899 年王懿荣识读，清末发现于殷墟（今河南安阳），是已知最早的成熟汉字体系。 |
| **金文** | 商周至秦汉铸刻于青铜器（钟、鼎等）的铭文，又称钟鼎文；内容多为册命、赏赐、征伐、盟誓，是先秦礼制与文字研究的直接实物。 |
| **简牍帛书** | 战国至魏晋书写于竹简、木牍与缣帛的文字。楚系简帛（郭店、上博、清华简等）与秦系简牍（睡虎地秦简等）极大补充了传世文献的缺环。 |
| **大篆** | 广义指小篆以前的古文字，含金文、石鼓文、籀文等。石鼓文为战国秦系代表，笔法圆融、结体端凝。 |
| **小篆** | 秦统一后李斯等整理的标准篆书，字形长方、笔画匀圆，为篆书正体，即《说文解字》所收篆文。 |
| **隶书** | 起于战国、成熟于汉，由篆书简便化（篆隶之变）演变而来，笔画方折、摆脱象形线条，是「古今文字」的分水岭。 |
| **楷书** | 汉末魏晋定型，由隶书草化、楷化而来，笔画规整、横平竖直，是沿用至今的规范正体。 |

## 快速开始

### 方式一：一键启动（推荐）
双击 `说文解字_启动服务.bat`，自动启动本地服务并打开浏览器 → http://127.0.0.1:8941/index.html

### 方式二：手动启动
```bash
python serve_8941.py     # 多线程静态服务，端口 8941
# 浏览器打开 http://127.0.0.1:8941/index.html
```

> ⚠️ 两点必须注意：
> 1. **不能直接双击 `index.html` 打开**。字形数据（`data/dataset.bin`，14.2MB）与笔顺数据（`data/stroke_data.json`，20.3MB）通过 `fetch()` 加载，`file://` 协议下会被浏览器 CORS 拦截 → 字形演变图与笔顺失效（内联的 8105 字基础数据、搜索、筛选仍可用）。
> 2. **请用 `serve_8941.py`，不要用 `python -m http.server`**。后者是单线程服务，会被本应用的并发大请求压垮，偶发把大文件发成空体，导致字形演变图整片空白。`serve_8941.py` 用的是 `ThreadingHTTPServer`，可并发。

> 部署前可跑一次完整性核验：`node tools/verify_deploy.cjs`（真克隆一份仓库、逐个拉取全部资源、校验字节与语法）。
>
> **关于「换台机器 `git clone` 后能否完整部署」**：可以完整**运行** —— `data/` 目录 39 个文件（`dataset.bin`、9 个字体、`characters.json`、`feihualing.json`、`cultural.json`、各 JS 模块）已全部入库。以下素材**不在仓库**（被 `.gitignore` 排除、仅存本地），缺它们只影响「**重新生成**数据」的能力，不影响运行：诗词语料、GlyphWiki 字源素材、PDF 研究资料。清单与重建路径见 [`docs/未入库素材台账.md`](docs/未入库素材台账.md)。

## 数据质量说明
8105 字经过三轮语义抽查与多轮程序化核查：六书以许慎《说文》构形为准；部首统一到康熙 214 部体系；笔画取 Unicode Unihan 权威数据；程序性错误（字段错位、反切误提取等）已清零；语义字段（六书/本义/今义/演变）AI 生成，抽样错误率已降至约 4%，页面通过来源标注区分权威与 AI 生成内容。
